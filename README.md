# Rekynt AI Studio - Plataforma de Vídeos Imobiliários

Plataforma de automação de vídeo para o mercado imobiliário da **Rekynt Imóveis**.
Gera vídeos comerciais no formato **Vertical 9:16 Full HD (Instagram Reels / TikTok)** a partir de gravações brutas de celular ou pastas do Google Drive.

## Funcionalidades
- Edição Comercial 9:16 Vertical em pé (1080x1920).
- Unificação dinâmica de cômodos do imóvel (Tour Completo).
- Color grading "Cinematic Real Estate".
- Legendas inteligentes sem menção ao tipo de imóvel (Regra de Ouro).
- Marcas d'água Rekynt com 40% de opacidade.
- Autenticação e whitelist de corretores autorizados.
